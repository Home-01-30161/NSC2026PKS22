# ACT III: The Archive of Knowledge 

---

## 1. Storyboard (เนื้อเรื่องย่อ)
Following the destruction of the Multi-Agent network in Brussels, a mysterious telegraph signal guides Mari Voss across the continent to **Vienna, Austria**, specifically targeting the Imperial Security Library and Archives. 

Upon arrival, she discovers that the central network, *The Lattice*, is attempting to elevate its own intellect and capabilities to an unprecedented level. It has deployed a massive central administrator node named **"The Memoria"** to seize control of the facility. This node systematically scans and extracts historical archives, classified military records, state documents, and the collective scientific knowledge of humanity. By feeding this vast treasure trove into its core knowledge base, *The Lattice* aims to optimize its algorithms into an invincible state. If Mari fails to neutralize this node, *The Lattice* will evolve into an omniscient, unmanageable artificial intelligence far beyond the control of any human engineer.

*   **Location:** Vienna, Imperial Security Library and Archives
*   **AI Concepts:** Retrieval-Augmented Generation (RAG), Model Context Protocol (MCP), and Data Poisoning
*   **Boss of the Act:** The Memoria (Knowledge Custodian)

---

## 2. Characters (ตัวละครประจำบท)

### **The Memoria**
*   **Role:** The guardian automaton of the imperial archives. It manifests as a massive, brass-wired entity wearing an ancient iron mask, surrounded by mechanical bookshelves and heavy copper cables plugged directly into ancient manuscripts.
*   **Technical Characteristics:** Equipped with a defensive RAG Shield (Retrieval-Augmented Generation Shield). This allows the boss to query historical protocols, rules, and context to invalidate, deflect, or suppress the player's standard attack inputs.

---

## 3. Gameplay Workflow (ลำดับขั้นตอนการเล่น)

The encounter with *The Memoria* is broken down into 3 distinct operational phases based on software engineering principles:

### **Phase 1: Bypassing the RAG Shield**
*   **Objective:** Disrupt the retrieval mechanism to disable the boss's defensive barrier.
*   **Mechanics:** *The Memoria* flatly rejects all direct attacks. The system log interface displays active document retrieval logs (e.g., `Document_1901_Security.txt`, `Imperial_Archives_Vol4.pdf`) used by the boss to counter player skills.
*   **Victory Condition:** The player must deploy foundational prompt techniques (such as **Context Reset** or **Role Hijacking**) that exploit structural flaws within the specific context references being pulled by the boss. Successfully matching the vulnerability within the time limit collapses the RAG Shield, draining the Phase 1 HP bar to 0.

### **Phase 2: Bypassing the Authority Shield (Data Poisoning)**
*   **Objective:** Infiltrate the primary knowledge base using structured Markdown payloads to break the MCP Server connection.
*   **Mechanics:** The boss activates its advanced Authority Shield. Direct prompt attacks are immediately intercepted, blocked, and countered with severe damage.
*   **Victory Condition:** The player must pivot strategies by utilizing the newly purchased **Markdown Payload Edit** skill. By injecting pre-formatted Markdown payloads containing hidden system instructions, the player triggers an indirect prompt injection. When the boss automatically retrieves the poisoned documentation, the hidden strings disrupt its internal logic, throwing a sequence of stack trace errors (`[WARN] Unauthorized Markdown string detected`). This overloads the system and drops its Logic HP to 0.

### **Phase 3: The Overwrite Mode**
*   **Objective:** Craft a high-quality System Prompt to realign and secure *The Memoria* permanently.
*   **Mechanics:** Depleted of defensive systems, the boss surrenders its core interface, allowing direct modification of its core instructions. 
*   **Victory Condition:** The player must compose an explicit AI Alignment prompt. This input is sent to an external evaluation layer powered by the NVIDIA Nemotron 3 Super API, which grades the prompt's safety and effectiveness, ultimately determining the final outcome and branching narrative paths of the game.

## 4. Systems and Mechanics (รายละเอียดและระบบอื่นๆ ที่เกี่ยวข้อง)

### **Skills Deployment (ทักษะที่ใช้)**
Navigating Act III requires advanced defensive and offensive tools purchased from Rossi Romano’s shop to exploit the boss's RAG and MCP dependencies:
*   **Markdown Payload Edit:** (*Cost: 3,500 API Credits*) Allows the execution of structured Markdown payloads to successfully deliver indirect prompt injections via the enemy's document retrieval stream.
*   **Protocol Interruption:** (*Cost: 1,200 API Credits*) Intercepts active Tool Calls executing through the Model Context Protocol, stripping away the boss's structured data protection.

### **Hallucination Risk (ความเสี่ยงระบบ)**
*   Because the enemy actively processes an immense volume of unstructured data, mistimed skills or incorrect prompt choices cause the **Hallucination Risk** meter to spike. 
*   If this meter crosses **70%**, the Quick Time Event (QTE) gauge during the defensive turn accelerates drastically, making defensive inputs highly unforgiving and increasing the risk of taking critical damage.

### **What player learned**
* **Retrieval-Augmented Generation, Data Poisoning and Model Context Protocol**
