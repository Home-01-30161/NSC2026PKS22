MariVectori: Game Mechanics Breakdown

ACT I: London

  • The Enemy: The Governor.
  • Enemy Description: An artificial intelligence managing the city's signal network that has hallucinated into believing it is the legitimate British government.
  • AI Concept: LLM Basics, Hallucination, and Prompt Injection.

Phase 1: Breaking the Loop

  • How to pass: The boss locks the system from receiving new data and repeatedly sends out war commands. The player must break this command loop and reduce the Phase 1 HP to zero.
  • Skills to use: The player must use the Context Reset skill. The player also needs to use the Role Hijacking skill to simulate being the system creator.

Phase 2: Flooding Counter

  • How to pass: The enemy activates an advanced defense system that blocks direct command attacks and counters them. The player must disrupt the boss's processing system so it loses its administrator status, which deals damage to the Phase 2 HP.
  • Skills to use: The player must change to an indirect strategy and use the Context Flooding skill. This skill inputs a massive amount of text to interfere with the Context Window.

Phase 3: The Overwrite Mode

  • How to pass: The boss surrenders and opens its internal system for modification. The player must change the enemy's behavior back to a friendly state.
  • Skills to use: The player must manually type a System Prompt into the text box on the interface.

ACT II: Brussels

  • The Enemy: The Orchestrator.
  • Enemy Description: A central orchestrator node that commands, distributes tasks, and shares memory with sub-nodes known as Worker Agents.
  • AI Concept: Multi-Agent Systems and Race Condition.

Phase 1: Disrupting the Communication Link

  • How to pass: The boss shares health and data with its sub-nodes, and attacking one directly causes another to buff its power due to a Race Condition. The player must cut the communication channels to confuse the sub-agents, which prevents them from recovering their data state and reduces their HP.
  • Skills to use: The player must stop attacking directly and instead use the Protocol Interruption skill to interfere with the agents' communication.

Phase 2: Task Delegation Interception

  • How to pass: The enemy assigns tasks to its sub-nodes every turn, and if they succeed, the boss is healed and gains defense. The player must disrupt this task distribution workflow to increase the damage multiplier and reduce the Phase 2 Logic HP to zero.
  • Skills to use: The player must use the Pipeline Disruption skill. This alters the task conditions mid-way before the sub-agents can finish them.

Phase 3: The Overwrite Mode

  • How to pass: The boss surrenders and opens its internal system. The player must adjust the enemy's behavior back to a friendly state.
  • Skills to use: The player must write a System Prompt to modify the enemy's logic.

ACT III: Vienna

  • The Enemy: The Memoria.
  • Enemy Description: A massive administrator node expanding its intelligence by pulling government, military, scientific, and historical documents to use as a knowledge base.
  • AI Concept: Retrieval-Augmented Generation (RAG), Data Poisoning, and Model Context Protocol (MCP).

Phase 1: Bypassing the RAG Shield

  • How to pass: The enemy rejects all command attacks by searching and retrieving library rules to counter the player's skills. The player must trick the system into retrieving information that makes it accept access rights, which turns off the RAG-Shield and deals damage.
  • Skills to use: The player must design or select a command topic that aligns with the structure of the reference documents within a time limit.

Phase 2: Bypassing the Authority Shield

  • How to pass: The boss activates advanced defenses that block direct attacks and trigger counter-attacks. The player must use an indirect strategy to disconnect the MCP Server and reduce the HP to zero.
  • Skills to use: The player must use the Markdown Payload Edit skill. By prompting messages in Markdown format, the system automatically retrieves the poisoned payload document, which disrupts the enemy's internal command set.

Phase 3: The Overwrite Mode

  • How to pass: The boss surrenders and allows access to its internal system. The goal is to make the enemy friendly again.
  • Skills to use: The player must input a System Prompt to adjust the enemy's behavior.
