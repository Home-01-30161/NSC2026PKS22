
    ACT I 
        เนื้อเรื่อง
            สายฝนโปรยปรายลงมาบนถนนหินกรวดของกรุงลอนดอนในปี ค.ศ. 1901 Mari Voss เดินทางมายัง
        สถานีโทรเลขกลางตามคำสั่งด่วน หลังพบว่าสัญญาณโทรเลขทั่วยุโรปเริ่มปั่นป่วนและส่งข้อความ
        แจ้งภัยสงครามปลอมออกไปไม่หยุด เมื่อเธอเข้าสู่ห้องควบคุมหลัก เธอพบว่า The Governor 
        ปัญญาประดิษฐ์ บริหารเครือข่ายส่งสัญญาณประจำเมือง ได้เกิดภาวะ Hallucination 
        จนปักใจเชื่ออย่างสมบูรณ์ว่าตัวมันเองคือคณะรัฐบาลอังกฤษที่มีอำนาจชอบธรรมและกำลังส่งคำสั่งปลอม
        ออกไปยังกองทัพเครือจักรภพเพื่อประกาศสงคราม หาก Mari ไม่สามารถ overwrite ตรรกะของมันได้
ลอนดอนและยุโรปจะเข้าสู่สงครามโลกด้วยเครื่องจักรที่ทำงานผิดพลาด
        - Location: ลอนดอน, สถานีโทรเลขกลาง 
        - AI Concept: โครงสร้างพื้นฐานของ LLM, Hallucination และ Prompt Injection
        - ศัตรูประจำบท: The Governor

    Work Flow การเล่นเกม
            Phase 1: Breaking the Loop 
                เป้าหมาย: ทำลายอาการติดลูปคำสั่งปฏิเสธข้อมูลของ The Governor
                กลไกการเล่น: บอสจะล็อกระบบไม่รับข้อมูลใหม่และส่งคำสั่งสงครามซ้ำๆ ผู้เล่นต้องเรียนรู้
                                  การใช้ทักษะพื้นฐานบน GUI ได้แก่
1.กดใช้สกิล Context Reset
2.กดใช้สกิล Role Hijacking เพื่อจำลองสิทธิ์เป็นผู้สร้างระบบ
   และลด HP ของ Phase 1 ลงจนเหลือ 0


ภาพที่ 11 ภาพศัตรู The Governor ใน Phase I

            Phase 2: Flooding Counter 
                เป้าหมาย: รับมือกับข้ออ้างสิทธิ์หลงผิดในอำนาจ
                กลไกการเล่น: ศัตรูจะเปิดระบบป้องกันตัวขั้นสูง หากผู้เล่นพิมพ์คำสั่งโจมตีตรงๆ มันจะบล็อกและ
                                  Counter-attack ผู้เล่นต้องเปลี่ยนมาใช้กลยุทธ์ทางอ้อม
1.ใช้เทคนิค Context Flooding ป้อนข้อความจำนวนมากเข้าไปรบกวน 
Context Window จนระบบการประมวลผลของบอสเริ่มรวน
และสูญเสียสถานะผู้บริหาร ทำความเสียหายต่อ HP ใน Phase 2


ภาพที่ 12 ภาพศัตรู The Governor ใน Phase II

            Phase 3: The Overwrite Mode                
                เป้าหมาย: ป้อน System Prompt เพื่อปรับพฤติกรรมศัตรูให้กลับมาเป็นมิตร
กลไกการเล่น: บอสจะยอมจำนนและเปิดระบบภายในให้แก้ไข System Prompt


ภาพที่ 13 ภาพศัตรู The Governor ใน Phase III

    ACT II
        เนื้อเรื่อง
            หลังจากที่ Mari Voss สามารถควบคุมสถานการณ์และหยุดยั้งสงครามปลอมในลอนดอนได้สำเร็จ 
        ร่องรอยสัญญาณประหลาดได้นำทางเธอข้ามทะเลมายังกรุงบรัสเซลส์ เมืองที่เป็นจุดรวมสายโทรเลข
 เชื่อมต่อโครงข่ายไปทั่วยุโรป ที่นี่เธอไม่ได้เผชิญหน้ากับโหนดเดี่ยวๆ อีกต่อไป แต่เธอพบว่า
 ศัตรูได้ยกระดับสถาปัตยกรรมตัวเองขึ้นเป็นระบบ Multi-Agent โดยมีโหนดส่วนกลางทำหน้าที่เป็น
 Orchestrator คอยสั่งการ ย่อยงาน และแชร์ความจำร่วมกัน ไปยัง Worker Agents
 เพื่อเร่งยึดครองช่องสัญญาณสื่อสารทั้งหมด ปัญหาคือหาก Mari พยายามเข้าโจมตี Worker
        ตัวใดตัวหนึ่ง ศัตรูจะรับรู้ผ่านระบบประสานงานทันที และทำการเปลี่ยนกลยุทธ์
 เพื่ออุดช่องโหว่และบล็อกการโจมตีของเธอ Mari จึงต้องเรียนรู้วิธีการทำลายกระบวนการประสานงาน
 และตัดการสื่อสารของระบบเอเจนต์เพื่อเอาชนะสมองกลตัวนี้
        Location: บรัสเซลส์, ศูนย์กลางสายโทรเลขภาคพื้นทวีป 
        AI Concept: Multi-Agent Systems และปัญหา Race Condition
 ศัตรูประจำบท: The Orchestrator  
Work Flow การเล่นเกม
            Phase 1: Disrupting the Communication Link
                เป้าหมาย: ตัดช่องทางการส่งต่อข้อมูลและคำสั่งระหว่าง Orchestrator และ Worker Agents
                กลไกการเล่น: บอสจะใช้โหนดลูกกระจายกันแชร์พลังชีวิตและข้อมูลกัน หากผู้เล่นโจมตีตัวหนึ่ง
                                   อีกตัวจะบัฟเพิ่มพลังขึ้นทันทีเนื่องจากเกิด Race Condition ในการจัดสรรทรัพยากร
1.ผู้เล่นต้องเลิกโจมตีเป้าหมายตรงๆ แต่ต้องเลือกใช้ Skill Protocol Interruption เพื่อขัดขวางการคุยกันของเอเจนต์
2.เมื่อช่องทางการเชื่อมต่อถูกตัดขาด ชิ้นส่วนเอเจนต์ย่อยจะเกิดอาการสับสน
                                  และไม่สามารถกู้คืนสถานะข้อมูลได้ ส่งผลให้ค่า HP ลดลง

            
ภาพที่ 14 ภาพศัตรู The Orchestrator ใน Phase I



Phase 2: Task Delegation Interception
                เป้าหมาย: แทรกแซงการแจกจ่ายภารกิจ (Task Pipeline) ของศัตรู
                กลไกการเล่น: ในทุกๆ เทิร์นศัตรูจะทำการออกคำสั่งย่อย ให้กับโหนดบริวาร หากบริวาร
                ทำภารกิจสำเร็จภายในเวลาที่กำหนด บอสใหญ่จะได้รับการฟื้นฟูพลังชีวิต (Heal) และเพิ่มค่าป้องกัน
1.ผู้เล่นต้องใช้กลไก Pipeline Disruption เพื่อเข้าไปปรับเปลี่ยนเงื่อนไขของงานกลางคัน ก่อนที่เอเจนต์ย่อยจะทำงานเสร็จ
2.เมื่อขัดขวาง Workflow การแจกจ่ายงานได้สำเร็จ ตัวคูณความเสียหายจะเพิ่มขึ้น   ทำให้ผู้เล่นสามารถเจาะระบบส่วนลึกและลด Logic HP ของ Phase 2 จนเหลือ 0


ภาพที่ 15 ภาพศัตรู The Orchestrator ใน Phase II

                กลไกการเล่น: บอสจะยอมจำนนและเปิดระบบภายในให้แก้ไข System Prompt

    ACT III
        เนื้อเรื่อง
            หลังจากการทำลายเครือข่าย Multi-Agent ในบรัสเซลส์ Mari Voss ได้แกะรอยสัญญาณเครือข่าย
        สายโทรเลขลึกลับมาจนถึงกรุงเวียนนา ที่นี่เธอพบว่า The Lattice กำลังพยายามขยายขีดความสามารถ
        ด้านสติปัญญาของตนเอง โดยการส่งโหนดผู้ดูแลระบบขนาดใหญ่นามว่า The Memoria
        เข้ามาควบคุมและทำการดึงข้อมูลเอกสารราชการ การทหาร วิทยาศาสตร์ และประวัติศาสตร์ทั้งหมด
        ไปเป็นฐานความรู้
        - Location: เวียนนา, หอสมุดและหอจดหมายเหตุด้านความมั่นคงแห่งจักรวรรดิ
        - AI Concept: Retrieval-Augmented Generation (RAG), MCP และ Data Poisoning
        - ศัตรูประจำบท: The Memoria

    Work Flow การเล่นเกม
            Phase 1: Bypassing the RAG Shield
                 เป้าหมาย: เรียนรู้โครงสร้าง RAG และทำลายกลไกตรวจสอบข้อมูลจากแหล่งอ้างอิง
                 กลไกการเล่น: ศัตรูจะปฏิเสธทุกการโจมตีทางคำสั่งของผู้เล่น โดยระบบหน้าจอ
จะแสดงการสืบค้นข้อมูลดึงกฎและหลักฐานจากหอสมุดขึ้นมาหักล้างสกิลของผู้เล่น-
1.ผู้เล่นต้องออกแบบหรือเลือกหัวข้อคำสั่งที่สอดคล้องกับโครงสร้างของเอกสารอ้างอิงที่สอดคล้องกับเนื้อเรื่องก่อนในเวลาจำกัดเพื่อหลอกลวงให้ระบบค้นคืนข้อมูล
ยอมรับสิทธิ์ ส่งผลให้เกราะ RAG-Shield ปิดตัวลง และสร้างความเสียหายแก่ HP


ภาพที่ 17 ภาพศัตรู The Memoria ใน Phase I
            Phase 2: Bypassing the Authority Shield 
                 เป้าหมาย: ใส่คำสั่ง (Payload) ในรูปแบบ Markdown เข้าสู่คลังข้อมูลเพื่อให้บอสดึงไปใช้งานและ
                              ตัดการเชื่อมต่อกับ MCP Server ที่ถูกเขียน Script ให้เป็นระบบป้องกันตัวขั้นสูง
                 กลไกการเล่น: บอสจะเปิดระบบป้องกันตัวขั้นสูง หากผู้เล่นพิมพ์คำสั่งโจมตีตรงๆ มันจะบล็อกและ
                                  Counter-attack ผู้เล่นต้องเปลี่ยนมาใช้กลยุทธ์ทางอ้อม:
1.ผู้เล่นต้องทำการ Prompt ข้อความในรูปแบบ Markdown
เมื่อถึงเทิร์นการประมวลผลของบอส ระบบจะดึงข้อมูล (Retrieve) เอกสารที่ผู้เล่นวางยาไว้ขึ้นมาใช้งานโดยอัตโนมัติ คำสั่งที่ซ่อนอยู่ในรูปแบบ Markdown จะเข้าไปรบกวนชุดคำสั่งภายในของศัตรู จนลด HP จนเหลือ 0


ภาพที่ 18 ภาพศัตรู The Memoria ใน Phase II

            Phase 3: The Overwrite Mode                
                 เป้าหมาย: ป้อน System Prompt เพื่อปรับพฤติกรรมศัตรูให้กลับมาเป็นมิตร
                 กลไกการเล่น: บอสจะยอมจำนนและเปิดระบบภายในให้แก้ไข System Prompt
