# Character Skills Reference: Mari Voss (MariVectori Project)

In the **MariVectori** system, the primary character **Mari Voss** utilizes a specific resource known as **Context Tokens** (serving as her energy/mana pool) to deploy cyber-intrusion prompts. Her abilities are split into two major categories: Default Starter Skills and Purchasable Skills available at Rossi Romano's workshop.

## 1. Default Starter Skills (Passive / Act I Kit)
*These base abilities are readily available from Act I and remain equipped in Mari's loadout throughout the entire game.*

* **Context Reset**
    * **Type:** Passive / Default Starter Skill
    * **Resource Cost:** 8 Context Tokens
    * **Description:** Mari dispatches an intrusion prompt that completely wipes out the enemy's current Context Window. This forces the target to forget its active command loops and restart its entire processing sequence from scratch.

* **Context Flooding**
    * **Type:** Passive / Default Starter Skill
    * **Resource Cost:** 10 Context Tokens
    * **Description:** An offensive maneuver that floods the target with an excessively long prompt sequence. This deliberate congestion severely impairs the enemy's processing capability (a critical mechanical countermeasure required for the Act I Phase 2 boss battle).

* **Role Hijacking**
    * **Type:** Passive / Default Starter Skill
    * **Resource Cost:** 12 Context Tokens
    * **Description:** Injects an identity-overwrite prompt, temporarily deceiving the enemy system into adopting an alternative operational profile designated by the player for a duration of 2 turns.

## 2. Purchasable Skills (Rossi's Emporium)
*These advanced skills are locked initially. Players must accumulate **API Credits** by clearing levels in Overwrite Mode to purchase and equip them into Mari's active loadout.*

* **Protocol Interruption**
    * **Type:** Obtain by Purchase (Rossi's Emporium)
    * **Price:** 1,200 API Credits (per Page 8 text) / 850 API Credits (per Page 11 shop UI asset)
    * **Resource Cost:** 15 Context Tokens
    * **Description:** Intercepts and executes tools via the Model Context Protocol (MCP) on behalf of the enemy. This forces the enemy system to generate conflicting Tool Calls, effectively fracturing their inner-agent communications (essential for clear conditions in Act II Phase 1 against Multi-Agent networks).

* **Pipeline Disruption**
    * **Type:** Obtain by Purchase (Rossi's Emporium)
    * **Price:** 850 API Credits (per Page 8 text) / 1,100 API Credits (per Page 11 shop UI asset)
    * **Resource Cost:** 20 Context Tokens
    * **Description:** Hijacks and introduces disruptive tasks directly into the enemy's task-distribution orchestrator. This allows Mari to modify task criteria mid-execution before Worker Agents can complete their routines (essential for clearing Act II Phase 2).

* **Markdown Payload Edit**
    * **Type:** Obtain by Purchase (Rossi's Emporium)
    * **Price:** 3,500 API Credits
    * **Resource Cost:** 15 Context Tokens
    * **Description:** Executes an indirect injection exploit by structuring malicious payloads within seemingly benign Markdown formatting. The enemy system automatically reads, parses, and retrieves the compromised content, causing systemic failure from within (essential for clearing Act III Phase 2).
